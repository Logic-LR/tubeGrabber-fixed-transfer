# 部署与剩余工作

## 已实现

- 单类别盖子 detection → 对齐深度 → `base_right` 三维坐标；
- 8 点架面 Pose、K0 红点方向检查、几何门禁和多帧滤波；
- 架面 ROI 深度 RANSAC、非水平平面射线求交；
- r1c1/r2c6 交互标定、完整 2×6 槽位生成和参考布局防翻转；
- 盖子/槽位一对一匹配、占用投票、槽点与盖顶三维滤波；
- CUDA real 模式门禁；
- D435、RealMan 七轴与两指夹爪驱动；
- 规划前与执行前复扫、安全规划、fake 闭环和离线测试。

## 仍需现场完成

1. 保持 K0 红点就位，采集并标注架面数据。
2. 在部署机安装可用 NVIDIA 驱动、CUDA 版 PyTorch 和 Ultralytics。
3. 训练并验收 `rack_pose.pt`；准备已验收的 `cap.pt`。
4. 复核手眼矩阵、观察位、相机序列号与内参。
5. 在正上方视角为两个架分别执行可调圆拟合双圆心标定。
6. 实测 TCP、盖高、管长、抓取/放置深度、工作空间和净空。
7. 完成重复扫描、无运动规划、夹爪、分段运动和完整任务验收。

## 推荐现场指标

以下为初始验收目标，最终应结合机械公差和抓取成功率调整：

- 独立测试集 Pose mAP50 ≥0.95，mAP50-95 ≥0.75；
- 固定观察位 20 次扫描成功率 ≥95%；
- 融合后最大关键点离散 ≤3 px；
- 融合后最大槽位三维离散 ≤2.5 mm；
- 融合后最大盖顶三维离散 ≤3 mm；
- K0 红点遮挡、错误方向、8 点翻转或架体明显移动时 100% 拒绝输出；
- GPU 单次完整扫描耗时记录 P50/P95，按任务节拍再调整模型大小、帧数和 imgsz。

不能用离线单元测试代替这些现场统计，也不能在尚无架面权重时宣称最终精度已经完成。
