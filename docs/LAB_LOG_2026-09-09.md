## Runtime behavior established today

- The wrist D435, `screw.pt`, and `cap.pt` are loaded in one observer session.
- Four-screw rack localization is reused from the original tubeGrabber method.
- If the K0 white marker is missed, the current rack pose code uses the image
  upper-left screw as the temporary K0 reference.
- Automatic source selection proceeds only when exactly one occupied slot is
  observed. With real `--auto-source`, visual failures immediately resample in
  the same process instead of exiting.
- One complete frame is sufficient. Each attempt can capture up to 12 frames.
- Reflective-cap D435 height outliers fall back to the calibrated 47 mm height,
  so a biased depth pixel cannot shift the grasp target.
- The pre-pick path uses one successful rack scan. The source-empty closure
  scan retries automatically after the arm reaches loaded home.
- Per-waypoint reached-pose comparison is disabled for motion continuity. SDK
  moves remain blocking; SDK/controller/communication failures still stop.
- Joint 7 commonly reports `0xF000` on a new SDK session. The real pick-home
  entry clears joint errors inside the same session before motion.
