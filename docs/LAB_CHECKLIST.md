# 真机分阶段检查清单

所有步骤在急停可触达、左臂收回、底盘锁定、右臂低速和现场监护下执行。不要为通过
检查而直接修改确认锁。

## 1. 静态与模型

- [ ] `screw_k0` 旁红点牢固、清晰且不遮挡螺丝孔中心。
- [ ] CUDA 版 PyTorch、Ultralytics、pyrealsense2 和 RealMan SDK 可导入。
- [ ] `models/cap.pt` 类别为 `{0: 'tube_cap'}`。
- [ ] `models/rack_pose.pt` 类别、8 点数量和顺序正确。
- [ ] Pose 模型通过独立序列 test 集验收。
- [ ] 手眼矩阵对应当前相机安装状态。

运行：

```bash
python -m tube_grabber doctor
```

## 2. 只读硬件

- [ ] `arm-status` 只连接并读取，确认七轴、Base/Arm_Tip、真实模式和上电状态。
- [ ] `camera-check` 保存一帧彩色/深度，确认序列号、尺寸、深度有效率和内参。
- [ ] `gripper-status` 只读取两指夹爪在线、使能、错误状态，不发送位置命令。
- [ ] 无 `atom` 或 `zhixing_ctrl.py` 覆盖 SDK 控制。

```bash
python -m tube_grabber arm-status
python -m tube_grabber camera-check
python -m tube_grabber gripper-status
```

## 3. 正上方标定与观察位

- [ ] 清空 `r1c1`、`r2c6`，低速将腕部相机移到架面正上方，确认线缆安全并保持静止。
- [ ] 分别执行 `calibrate-rack`；自动拟合后人工调整两个圆的圆心和半径。
- [ ] 两个圆周贴合槽边，最终十字圆心准确落在 `r1c1`、`r2c6` 中心。
- [ ] 绿色 2×6 网格中心与所有孔中心一致；方向从 r1c1 到 r2c6 正确。
- [ ] 标定保存后低速回到正常观察位，核对位置、姿态、视野并设置观察位确认锁。
- [ ] 在无架面、低速和急停监护下验证 `transfer` 可从允许的起始区自动到达观察位。
- [ ] 标定后重复 20 次 `scan`，记录成功率、关键点/槽点/盖顶抖动和耗时。
- [ ] 空架、满架和多种占用组合均能稳定识别；方向翻转测试必须被拒绝。

## 4. 无运动规划

- [ ] 实测 TCP 偏移、管长、盖高、抓取深度、放置深度、工作空间和净空。
- [ ] `plan-transfer` 的源盖顶、目标孔、TCP 和全部法兰航点与实物一致。
- [ ] 对边界槽位、错误占用、架体移动、遮挡、深度缺失分别测试拒绝路径。

## 5. 夹爪与低速动作

- [ ] 已通过 `gripper-status` 确认两指夹爪在线、使能且无错误。
- [ ] 在安全位置低速测试 170/135 开度，确认实际回读、力和超时门限。
- [ ] 分段验证接近、下降、夹紧、抬升、平移、放置和释放。
- [ ] 验证异常时减速停止；通信异常时使用物理急停。

## 6. 完整任务

- [ ] 设置运动参数确认锁后，先执行最安全的近距离同架任务。
- [ ] 自动进观察位前确认物理空载并输入 `EMPTY`；输入 `MOVE` 前再次确认现场和急停。
- [ ] 验证执行前第二次扫描确实重建抓取计划，不执行首轮旧坐标。
- [ ] 验证携管时停在目标高位走廊复检，且携管进入低观察位会被拒绝。
- [ ] 验证目标复检使用最新三维槽点重新规划放置下降。
- [ ] 验证放置后自动回观察位；最终源空、目标占用闭环失败时任务必须报错。
- [ ] 用多组源/目标统计成功率；未达到目标前不启用自动连续任务。
