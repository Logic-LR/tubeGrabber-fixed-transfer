# 架构说明

## 模块边界

| 层 | 职责 | 禁止事项 |
|---|---|---|
| `core` | mm/rad 坐标、槽位、观测和硬件端口 | 不导入模型或 SDK |
| `vision` | 8 点 Pose、红点方向、滤波、平面、盖子 XYZ、槽位状态 | 不发送运动 |
| `workflow` | 源/目标状态、复扫与抓放顺序 | 不读取 YOLO 或 SDK |
| `motion` | TCP/法兰转换、轨迹和工作空间检查 | 不理解 rack/row/column |
| `hardware` | D435、RealMan、两指夹爪 SDK 翻译 | 不决定业务目标 |
| `app/cli` | 组装、生命周期、人工门禁和运维入口 | 不放视觉或运动算法 |

跨层对象使用 dataclass；位置统一 mm，角度统一 rad，工作坐标系统一
`base_right`。手眼矩阵方向为 `end_right <- camera_rightwrist`，运行时组合为
`base_right <- camera_rightwrist`。

## 一次真实扫描

1. `transfer` 自动移动到已确认的固定观察位；只读 `scan/plan-transfer` 只检查当前位置。
2. 连续采集配置数量的对齐 RGB-D 帧；每帧采集前后及整个窗口内检查机械臂未移动。
3. `rack_pose.pt` 每帧输出一个 `rack_surface` 和 8 个有置信度的点。
4. 检查 K0～K3 构成凸四边形、对边尺度合理、四个螺丝孔在各自象限。
5. 检查 `screw_k0` 邻域红色占比合格且明显高于其他螺丝孔。
6. 以逐点中值为中心剔除整帧异常，再对保留帧取中值；关键点最大抖动超限即失败。
7. 将 8 点转换到单位架面，与标定参考布局比较，拒绝关键点语义错误或异常形变。
8. 每个保留帧在架面四角 ROI 内排除边缘、8 点邻域和盖框，使用深度点 RANSAC 拟合平面。
9. 将标定的 `r1c1/r2c6` 归一化锚点通过当前四角单应性展开为 2×6 槽位像素，射线与当前平面求交得到 12 个三维槽点。
10. `cap.pt` 只检测 `tube_cap`。框中心按槽间距门限一对一匹配槽位；盖顶深度转到 `base_right`，并检查其离架面高度。
11. 跨帧聚合槽点、盖顶和占用状态。占用投票、槽点/盖顶三维离散度任一不合格即失败。
12. 输出完整 `RackObservation`，包含 12 槽、8 点和稳定性统计。

没有 `empty_hole` 类。空槽定义为：在已标定槽位门限内没有稳定的盖子检测。

## 正上方双圆心标定

`calibrate-rack` 使用与扫描相同的多帧 Pose 和红点门禁，但不要求处于正常运行观察位，
所以操作者可以把相机低速移动到架面正上方。机械臂必须在整个采集窗口保持静止。

操作者先在 `r1c1`、`r2c6` 附近各点一次，Hough 圆拟合产生初始圆，再通过拖动和
键盘微调圆心、半径。确认后的两个圆心通过 `image -> unit rack` 单应性转换为
归一化坐标：

```text
slot(row, column) = first_anchor
  + row_fraction    * (last_anchor.v - first_anchor.v)
  + column_fraction * (last_anchor.u - first_anchor.u)
```

运行时再通过当前 `unit rack -> image` 单应性投影。这样正上方标定结果可以用于正常
观察视角，槽位网格随当前架面透视更新，而不是复用标定图片的固定像素。8 点参考也
保存为单位架面坐标，跨视角检查螺丝孔布局。保存使用同目录临时文件原子替换，默认
拒绝覆盖。

## 平面与三维坐标

架面不是通过盖高反推，也不假定严格水平。RANSAC 平面在 `base_right` 中表示为：

```text
normal · point_mm + offset_mm = 0
```

法向朝相机定向，使盖顶离架面的有符号高度为正。每个槽位通过彩色相机去畸变射线
与该平面求交。`RackObservation.plane_z_mm` 仅作为 12 槽 Z 的中值摘要；真实放置
高度以目标槽自己的 `hole_on_plane_base.z_mm` 为基准，支持轻微架面倾斜。

## 安全与复扫

正式任务先在观察位生成预览；获得 `MOVE` 授权后重新执行完整多帧扫描，并从第二次
观测重建抓取计划，不执行首轮旧坐标。抓起后只移动到目标高位走廊，从当前腕部相机位姿
重新识别架面并计算目标槽三维坐标；目标仍空、源已空、架体与其他槽稳定时，才从高位
使用最新目标坐标规划下降。携管状态禁止进入较低的全局观察位。

释放并撤离后，以 `movej_p` 返回同一全局观察位并执行最终多帧扫描。只有源槽为空、
目标槽占用且其他槽未异常变化时任务才成功。真实运动前还检查：

- 右臂七轴、Base/Arm_Tip 坐标系已切换并回读；
- 控制器为真实模式、已上电、控制器与关节错误为零；
- 没有已知后台进程覆盖 SDK 指令；
- TCP、工作空间、工具姿态、单段距离和携管净空均通过；
- 操作者先确认空载并输入 `EMPTY`，再在预览后输入 `MOVE`。

软件不是安全认证系统，急停、控制器限位、低速示教和现场监护仍是最终保护。
